BLOCKCRAFT

a tiny Minecraft clone — vanilla JS + WebGL, no build step

Look & move

  • Mouse — look around
  • W A S D — move
  • Space — jump / swim up
  • Shift — sneak (slow)
  • F — toggle flight
  • Double-space — also toggles flight

Build

  • Left click — break block
  • Right click — place block
  • 1–9 / wheel — select block
  • P — save world
  • Esc — release mouse

The world is procedural — add ?seed=1234 to the URL to explore a different one.
